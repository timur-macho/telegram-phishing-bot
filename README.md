# Telegram Bot для идентификации фишинговых ссылок и вредоносных файлов

Бот для проверки ссылок, файлов и голосовых сообщений на фишинг и вредоносное содержимое с использованием VirusTotal API и LLM анализа через OpenRouter.

## Возможности

- 🔍 Проверка ссылок на фишинг
- 📁 Проверка файлов на вредоносное содержимое
- 🎤 Автоматическая расшифровка голосовых сообщений (Whisper)
- 📊 История проверок за любой месяц
- 🛡️ Безопасность: OWASP Top-10, валидация данных, rate limiting

## Требования

- Python 3.10+
- Telegram Bot Token
- VirusTotal API Key
- OpenRouter API Key

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   # или
   source venv/bin/activate  # Linux/Mac
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните переменные окружения:
   ```bash
   copy .env.example .env  # Windows
   # или
   cp .env.example .env  # Linux/Mac
   ```

5. Запустите бота:
   ```bash
   python src/main.py
   ```

## Если проверка не работает

- **«Анализ временно недоступен»** — чаще всего сбой OpenRouter (ключ, модель или сеть). Проверьте `OPENROUTER_API_KEY` и `OPENROUTER_MODEL` в `.env`, откройте логи: `logs/bot.log`.
- **«Сервис проверки временно недоступен»** — сбой VirusTotal. Проверьте `VIRUSTOTAL_API_KEY` в `.env` и логи.
- При ошибках 401/429 в логах проверьте корректность API-ключей и лимиты сервисов.

## Безопасность

- Все API ключи хранятся в переменных окружения
- Telegram ID пользователей хешируются (SHA-256)
- Строгая валидация входных данных
- Защита от SSRF, prompt-injection
- Rate limiting для защиты от злоупотреблений
- Данные хранятся не более 6 месяцев
